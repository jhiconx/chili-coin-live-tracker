# CHI × Cronos — Standalone Site Source

This branch is a standalone source snapshot of the three-page CHI × Cronos PWA (Pitch, Distribution, Growth Model). It is intended as a staging point for migration into a **dedicated GitHub repository**.

- Entry point: `index.html`
- PWA files: `manifest.webmanifest`, `sw.js`
- Local brand assets: `assets/chili-mascot.webp`, `assets/chi-mark.png`, `assets/favicon.png`
- The Crypto.com logo hat patch is an HTML/CSS overlay visible in the homepage hero.
- Iconx campaign photography and third-party brand logos remain linked to their existing public sources.
- Framework: static HTML/CSS/JS (Vercel preset: Other)
- Production source is still `main:cronos-gtm/` until the Vercel Git connection is migrated.

Do not switch the existing Chili Coin live tracker production deployment to this branch. This branch is only a standalone site snapshot, not a new GitHub repository.
